### 外观与速率

- **胶囊风格的由来**：先做了 A–F 六种方案，看完 iTerm 实渲染预览后全部保留为 `pill_style` 的可选

  明暗定极性。
- **$/h 半衰期 600 s → 1200 s**（10-28）：用本会话 601 条账本逐分钟重放，600 s 时单笔大请求会让
  读数一分钟内跳 $14（一天 2 次 >$8），1200 s 把最大跳变压到 $7.2、>$8 的跳变归零；代价是达到 90%
  的时间从约 30 分钟变成约 50 分钟。15 分钟滑动窗口更跳（单笔花费进出窗口即阶跃，>$3 跳变 8 次），

- **今日花费**：靠「渲染过状态栏的会话」列表时，实测漏了一个 $0.28 的无头会话。

  （`src-tauri/src/services/usage_stats.rs`）把今日用量算成 `proxy_request_logs` + `usage_daily_rollups`

### 兼容性与 CI

- **Linux 实测与 CI 子集**（10-31 → 11-17）：Debian 12.15（bash 5.2.15、Python 3.11.2、非 root、GNU
  coreutils）在 Docker 里跑全量 197 项通过，唯一跳过的是「系统 bash 是 3.2」那条 macOS 专用用例。
  当时 CI 的 Linux 作业只跑 `cache subagent freshness install doctor`，理由是金样与配色矩阵是平台
  无关的纯计算；11-17 改为全量——渲染、tokens、色板同样依赖 runner 上的 bash 与 jq 版本，而全量
  只要约一分钟。
- **Linux runner 的 mkdir 异常**（10-31）：GitHub `ubuntu-latest`（kernel 7.0.0-azure）上，并发用例里
  两个进程都记录 `mkdir-ok isdir=y`，没有一次 `mkdir` 失败；同机线程屏障探针 0/500，本地 Debian 12 /
  Ubuntu 24.04 容器各 20+ 轮 0 失败。
- **bash 4.2 实测**（10-31）：Debian 12 里源码编译 4.2.0 跑全量，首轮 7 项失败里有 6 项由空格式
  `printf -v` 引起（占位符 `-` 原样上屏：`5h -%`、`out -`、`hit -%`、`m-`，中转站费用也回落到 stdin
  值）；另一项是 `-nt` 只比较到秒，同一秒内切换分支被当成「没变」。修复后 0 失败。11-17 起由 CI 作业
  每次验证；编译要点：2011 年的 K&R 风格 C 在默认 C23 的新 gcc 下编不过，`-std=gnu89` 必须写进
  `CC` 而不是 `CFLAGS`（`builtins/` 里的 `mkbuiltins` 不吃 `CFLAGS`）。首轮即全量通过，
  `printf '%(%s)T' -1` 在 4.2.0 上工作正常。
